# Build & Brew: The AI Dojo · Catalog

> *A free weekly live cohort. One real AI project built together, toward the high-performing solutions engineer.*

The dojo runs a menu of 100 ranked builds across the twelve solutions-engineering roles, in do-first order, from Foundation to Core to Advanced. Each build ships four things: a validated working system, a stakeholder readout, a teach-back, and an honest after-action review. This catalog lists what has shipped so far.

## Systems

| 7 | [Prove an IAM Permissions Boundary](./systems/iam-permissions-boundary-proof/) | Cloud security and authorization evidence | A permissions boundary tested rather than assumed: eight decisions frozen before the simulator ran, an unbounded control condition first returning allowed for the disputed CreatePolicyVersion, then refused with AllowedByPermissionsBoundary false once the ceiling was attached. Landing a second month beside the first left all three layer counts untouched, so file arrival never widened scope |
| 11 | [Is Better Search Worth the Wait?](./systems/retrieval-rerank-benchmark/) | Retrieval evaluation and measured cost | A four-row retrieval benchmark that attaches the clock to a reranker: dense, sparse, hybrid and hybrid plus a cross-encoder confined to the same 50 candidates, all on one frozen 20-query sample.
