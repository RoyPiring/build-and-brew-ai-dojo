# Build & Brew: The AI Dojo · Catalog

> *A free weekly live cohort. One real AI project built together in about 45 minutes, toward the high-performing solutions engineer.*

The dojo runs a menu of 100 ranked 45-minute builds across the twelve solutions-engineering roles, in do-first order. Each build ships four things: a validated working system, a stakeholder readout, a teach-back, and an honest after-action review. This catalog lists what has shipped so far.

## Systems

| # | System | What it drills | What it proves |
|--:|---|---|---|
| 1 | [Your First Rep: Ship a Global-Problem Card Through GitHub](./systems/first-rep-github/) | The delivery loop | A sourced, honest one-page card shipped through a repo, a board, a pull request, and a tagged release |
| 2 | [Testable Multi-Provider Network Module](./systems/testable-multi-provider-network-module/) | Software and platform engineering | A reusable network module, tests that prove it, and a defended choice of infrastructure tool |
| 3 | [Error Budget Control Room](./systems/error-budget-control-room/) | Site reliability engineering | An error budget that decides whether a page is worth waking someone, checked against a replayed incident |
| 4 | [The Delivery Scoreboard](./systems/delivery-scoreboard/) | DevOps and delivery | The four delivery keys computed from a real repo, with an honest line on what each does not prove |
| 5 | [Spec-Driven Feature Factory](./systems/spec-driven-feature-factory/) | AI integration engineering | A written spec as the source of truth, an agent that builds from it, and a plan a reviewer can read |

**5 of 100 shipped.** The rest arrive one live build at a time.
